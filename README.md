
# 📊 Projeto Power BI – Dashboard Interativo com Navegação e Indicadores | DIO

Este projeto foi desenvolvido como parte do bootcamp de **Análise de Dados da [DIO](https://www.dio.me/)**.  
O objetivo foi aplicar na prática os conceitos de **design, navegação e interatividade no Power BI**, criando um relatório dinâmico e intuitivo.

---

## 🧠 Sobre o Projeto

O dashboard foi desenvolvido com foco na **experiência do usuário**, utilizando botões de navegação e indicadores que permitem explorar diferentes visuais dentro de um mesmo relatório.  

🔍 **Destaques do projeto:**
- 🔘 **Botões de navegação** entre páginas e seções  
- 🧭 **Indicadores (Bookmarks)** para alternar entre visuais  
- 🖼️ **Botões com imagens associadas** para tornar a interação mais intuitiva  
- 🎚️ **Segmentadores (Slicers)** aplicados para filtragem dinâmica dos dados  
- 📊 **Visuais de mapa, gráfico de pizza e gráficos comparativos**  

---

## 🚀 Tecnologias e Ferramentas Utilizadas

- **Power BI Desktop e Power BI Service**  
- **Power Query** (para tratamento e organização dos dados)  
- **Excel** (como fonte de dados)  
- **Indicadores e botões de imagem** (para navegação entre visuais)  
- **GitHub** (para versionamento e portfólio)
